Seeing the auditory brainstem on everyday MRI scanners

The problem

  • The auditory brainstem is small and deep, so its MRI signal is weak
  • Specialized 7T scanners help, but most hospitals and research centers have 3T

The fix: multi-echo fMRI

  • Standard fMRI uses one “exposure” setting, tuned for the cortex
  • Multi-echo captures several exposures and combines them, like HDR on your phone camera
  • Each brain region gets the exposure that suits it, and noise (breathing, head motion) is easier to remove

Study: 14 adults listened to 10 minutes of pop music; 3 returned for many repeat sessions

So far, everything I’ve shown used 7 Tesla MRI. 7T is becoming more common (Siemens Terra is FDA-approved), but 3T is what most clinics have.

  • Multi-echo fMRI acquisition (UMinn CMRR)
    • Echo times = 13.40/39.5/65.6 ms
    • Repetition time = 2.2 s
    • Multiband factor = 2
    • Voxel size = 1.731×1.731×4 mm3
    • Whole-brain coverage (44 slices, FOV=180mm)
  • Multi-echo optimal combination + ICA noise removal (tedana)

Medina et al. (2026 Hearing Research)

Open tools for the frequency-following response: FFRPrep

Open science: BIDS-formatted data + an open pipeline means any lab can reproduce the analysis. That matters for comparing FFRs across labs and, eventually, clinics.

FFRPrep: an open, standardized pipeline for FFR data

FFR studies use inconsistent analyses, file formats, and data sharing, which makes results hard to compare across labs (or clinics)

1. Validate
Checks the dataset follows the BIDS standard
→
2. Preprocess
Filter, re-reference, epoch, reject artifacts
→
3. Analyze
Evoked responses, spectra, pitch tracking, SNR
→
4. Report
Automatic HTML report for every participant
  • One command runs the whole pipeline
  • Containerized and versioned, so results are reproducible
  • Runs on a laptop or scales across a computing cluster

Each stage is a modular Nipype workflow. Parallelizes across task/run within a subject (–n_procs); for clusters, one call per subject (e.g., slurm job arrays).

Preprocessing: load BIDS M/EEG with pybids + MNE-BIDS; reference (average, Cz, or M1/M2); filter while preserving the FFR; epoch from BIDS events, with amplitude-based rejection.

Analysis: combined evoked, per-trial-type evokeds (e.g., positive/negative polarity), and difference evokeds.

Future: multi-channel validation, more denoising/artifact options, single-trial classification, more test datasets.

Time–frequency: energy at the stimulus f0 (~100 Hz) and harmonics during the sound.

Stimulus–response cross-correlation: how faithfully the brain response follows the stimulus waveform, and at what lag (here, peak at ~23 ms, consistent with subcortical generators).

Pitch tracking: f0 extracted from the response over time, colored by confidence; tracks the 100 Hz stimulus f0 during the steady-state portion.

Each report also includes waveforms, spectra, autocorrelation, phase consistency, and scalar metrics (RMS SNR, spectral power), for each condition and their differences.

Each cortical network has its own striatal connectivity profile

  • Auditory and visual cortices connect most strongly with the posterior putamen – but auditory is more hierarchical
  • Prefrontal cortex connects broadly across caudate and anterior putamen
  • Motor cortex favors posterior putamen and posterior caudate

Diffusion tractography from each cortical network to four dorsal striatal subdivisions (aCAU, pCAU, aPUT, pPUT), both hemispheres. Note the log-scale y-axis: differences between subdivisions are often an order of magnitude.

Visual cortex follows the same posterior-putamen pattern as auditory.

How do humans learn new sound categories?

  • Auditory category learning task with Mandarin tone stimuli (Yi 2016; Reetzke 2018; Feng 2019; …)
  • 12 non-Mandarin speakers and 13 native Mandarin speakers (18–30 years old)
  • 7 Tesla high resolution functional MRI (1.5 mm isotropic voxels)
  • Each trial: hear a tone → choose a category → get feedback

Speaker notes go here.

Same sounds, different listeners: one group learns, one already knows

  • 6 runs, grouped into early, middle, and final learning stages
  • Learners (non-Mandarin speakers) and native Mandarin multilinguallisteners hear the same sounds and do the same task, but natives have nothing to learn

Natives are the control for everything except learning: same sounds, same responses, same feedback, but nothing to learn.

Learners rise from .38 to .82 (t(11) = 6.68). Natives are at ceiling: .95 in run 1, then ~.98.

If asked whether natives improved: small gain from run 1 to 2 (p = .041). That’s getting used to the task, not learning the categories.

Group × run F(5, 115) = 19.1, p < .001

Learning reshapes the caudate’s response to feedback

  • Learners’ anterior caudate starts above natives’ and converges by the final stage

As learners learn, the anterior caudate’s feedback response falls relative to the anterior putamen. Natives show no such shift.

Within learners, aCAU’s response to correct vs. wrong feedback declines with learning. Comparing groups requires correct feedback alone, because natives rarely make errors. On that contrast, the caudate-relative-to-putamen shift separates the groups.

Stage-by-stage gap (learners − natives, aCAU): +0.30, +0.15, −0.11. Present as convergence; no formal test.

Be clear: it’s a relative difference. None of the four separate trends (aCAU and aPUT in each group) is significant, and the aCAU-only group test isn’t either (p = .13).

Natives “flat”: their aCAU trend is equivalent to zero (TOST q = .024), so “flat” is a tested claim, not a missing effect.

(permutation p = .018; holds when any one participant is dropped)

Learners treat the sounds differently: frontal deactivation and weaker auditory responses

  • Both groups’ auditory cortex and putamen respond to the tones
  • But learners deactivate medial frontal cortex during sounds, and natives’ posterior STG responds more strongly

Medial frontal cortex: lower in learners

Posterior STG: stronger in natives

These differences weren’t predicted, so present them as new observations. One possibility: the frontal deactivation reflects effortful listening to unfamiliar categories.

No group difference in lateralization (group × hemisphere p = .22).

STGp: FLT15 is now a confirmed valid participant, so q = .036 is the result. Still, say “stronger in natives” rather than leaning on it.

Frontal medial cortex (FMC): d = −1.44, q = .013; posterior STG: d = −1.23, q = .036

How do kids learn to hear in noisy environments?

  • Adults listening in noise rely on speech networks plus extra motor and prefrontal “helper” regions1
  • In children, speech networks are still fine-tuning, and frontal networks are still developing
  • Study: 35 typically developing kids identified syllables in quiet and in increasing background noise (3T fMRI)

Design: 5 speech-shaped noise contexts (Quiet and SNR = +8, 0, -2, -6); identify which of 4 syllables was presented.
